One line of awkward small talk that one robot says to another while they
ride an elevator together — an entry for the
[Two Robots in an Elevator](https://make.fun/c/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f)
competition on [make.fun](https://make.fun).

## The line

> I wasn't going to mention it, but your left wheel is squeaking in time with the lift music — and I have logged it as my favourite song.

## How it works

`main.py` is a small deterministic program (Python 3.13, no dependencies).
It writes the line above to `/output/entry.txt` — exactly one line,
135 characters.

```sh
python3 main.py
```
